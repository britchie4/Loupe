    How it works

    Point
    Loupe highlights what is under your pointer and names it.
    Leave a note
    Click and say what should change. Each note gets a numbered badge.
    Hand it off
    Tell your agent “Check my Loupe notes”. It asks on the note if unsure, changes your code, and the badge turns green.
    Or copy
    No agent connected? Click Copy and paste your notes into any coding agent.

    A copied note:

    ## App Feedback: Weekend Planner

### 1. AXButton[title="Save Plan"]
**Location:** AXWindow[title="Weekend Planner"] > AXGroup > AXButton[title="Save Plan"]
**Search patterns:**
- `Text\("Save Plan"\)`
- `Button\("Save Plan"\)`
- `AXButton.*Save Plan`
**Feedback:** Make this button bigger

    Agents can look. They can never touch.

    Can
    Read your notes. Ask a question on a note. Mark a note done. Look at the app you picked.
    Never
    Click or type in your apps.
    Off by default
    You turn Agent Link on in Settings. The connection stays on your Mac.

    Set up Agent Link

    1. Turn on Agent Link in Loupe's Settings.
    2. Add Loupe to your agent with the command below, or the button in Settings.
    3. Start a new session in your agent.

    Paste into Terminal or a Claude Code session.

    claude mcp add --scope user loupe -- /Applications/Loupe.app/Contents/MacOS/Loupe --mcp

    Paste into Terminal or a Codex chat.

    codex mcp add loupe -- /Applications/Loupe.app/Contents/MacOS/Loupe --mcp

    Click Add to Cursor in Loupe's Settings, or add this to ~/.cursor/mcp.json:

    {
  "mcpServers": {
    "loupe": {
      "command": "/Applications/Loupe.app/Contents/MacOS/Loupe",
      "args": ["--mcp"]
    }
  }
}

    Xcode's built-in agents keep their own settings. Paste each line into Terminal.

    CLAUDE_CONFIG_DIR="$HOME/Library/Developer/Xcode/CodingAssistant/ClaudeAgentConfig" claude mcp add --scope user loupe -- /Applications/Loupe.app/Contents/MacOS/Loupe --mcp
    CODEX_HOME="$HOME/Library/Developer/Xcode/CodingAssistant/codex" codex mcp add loupe -- /Applications/Loupe.app/Contents/MacOS/Loupe --mcp

    Click Copy setup prompt in Loupe's Settings and paste it into your agent, or register this as a local MCP server named loupe:

    /Applications/Loupe.app/Contents/MacOS/Loupe --mcp

    Optional: a skill that teaches your agent the notes routine.

    npx skills add britchie4/Loupe

    Get Loupe

    Free and open source (MIT). macOS 14 or later.

    Download .dmg Build from source

    Permission. Loupe asks to read other apps on first launch. macOS 27 and later call this “Device Control and Data Access”. Earlier versions call it “Accessibility”.

    Updating. Version 1.2.1 and later update themselves: choose Check for Updates… from the menu bar icon, or right-click the toolbar. On an older version, quit Loupe, download the latest, and drag it to Applications. Your permission carries over.
